# Игра 2048

Классическая игра 2048 на TypeScript, React и Tailwind CSS.

## Особенности

- **Управление с клавиатуры + свайпы на мобильных**
- **Подсчет очков + лучший результат**
- **Определение победы/поражения**
- **Интуитивно понятный UI/UX и адаптивность под мобильные устройства**

## Быстрый старт

### Предварительные требования
- **Node.js (версия 16 или выше)**
- **npm или yarn**

### Установка и запуск

1. **Клонируйте репозиторий**

```sh
git clone https://github.com/vulkan790/2048.git
cd 2048
```

2. **Установите зависимости**
```sh
npm install
```
3. **Запустите в режиме разработки**
```sh
npm run dev
```

4. **Откройте в браузере**

5. **Сборка для production**
```sh
npm run build
```

## Используемые технологии

- **Frontend:** React + TypeScript
- **Стилизация:** TailwindCSS
- **Сборка:** React-scripts

## Цель игры

**Объединяйте плитки с одинаковыми числами, чтобы получить плитку 2048!**

### Как играть:
1. **Используйте стрелки клавиатуры (← → ↑ ↓) для перемещения плиток**
2. **На мобильных устройствах используйте свайпы**
3. **При столкновении двух одинаковых плиток они объединяются в одну**
4. **После каждого хода появляется новая плитка (2 или 4)**
5. **Игра заканчивается, когда нет свободных клеток и возможных ходов**

# Game 2048

A classic 2048 game built with TypeScript, React, and Tailwind CSS.

## Features

- **Keyboard controls + mobile swipes**
- **Score counter + best score tracking**
- **Win/lose detection**
- **Intuitive UI/UX and mobile responsiveness**

## Quick Start

### Prerequisites
- **Node.js (version 16 or higher)**
- **npm или yarn**

### Installation and Running

1. **Clone the repository**

```sh
git clone https://github.com/vulkan790/2048.git
cd 2048
```

2. **Install dependencies**
```sh
npm install
```
3. **Run in development mode**
```sh
npm run dev
```

4. **Open in your browser**

5. **Build for production**
```sh
npm run build
```

## Technologies Used

- **Frontend:** React + TypeScript
- **Styling:** TailwindCSS
- **Build tool:** React-scripts

## Game Goal

**Merge tiles with the same numbers to get the 2048 tile!**

### How to play:
1. **Use arrow keys (← → ↑ ↓) to move tiles**
2. **On mobile devices, use swipe gestures**
3. **When two identical tiles collide, they merge into one**
4. **After each move, a new tile (2 or 4) appears**
5. **The game ends when there are no free cells and no possible moves**
